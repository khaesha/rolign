# Output language rules

Use `en` for English prose and `id` for Indonesian prose. No language option
means `en`. Reject any missing, unsupported, or duplicate `--language` option
before generation or storage.

Apply the selected language only to generated prose: analysis explanations,
gaps, recommendations, and cover-letter text. Do not translate or alter JSON
field names, score categories or values, record metadata, company or role
names, employers, titles, dates, metrics, skills, achievements, resume
evidence, or quoted job keywords. Translation must not add, remove, or broaden
any factual claim.
